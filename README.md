# Znak extension for Zed

Language support for the [Znak](https://codeberg.org/noClaps/znak) markup language.

> [!NOTE]
> This extension and the Tree-sitter grammar are vibe-coded.

## Install

Clone this repository

```sh
git clone https://github.com/noClaps/zed-znak.git
```

In Zed, open the command palette, run **zed: install dev extension** in Zed, and select the `zed-znak` directory.
